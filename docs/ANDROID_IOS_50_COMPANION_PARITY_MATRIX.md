# Android / iOS 5.0 Companion Parity Matrix

Register: product

This matrix tracks Android phone parity with the iOS 5.0 Companion outcomes. iOS remains the behavioral reference; Android remains Material-native, phone-first, Play Billing only, local-first, and scoped away from export/import/backup/cloud/accounts/analytics/support tips.

| Outcome | iOS 5.0 reference | Android parity target | Current Android status |
| --- | --- | --- | --- |
| First-screen clarity | Today opens with a Companion card that answers rule, live state, and next faithful action. | Today renders an Android companion-first card above existing dashboard content. | Implemented with `CompanionSnapshotEngine` and `TodayUiState.companionSnapshot`. |
| Rule authority near decisions | Rule copy includes rationale and source close to the action. | Companion rule decision includes obligation, rationale, source line, and today titles. | Implemented in `core:rules`; UI shows source line in the first card. |
| Live fasting state | Today and Track Fast reflect active fast state and recent recap. | Shared snapshot exposes active, target reached, eating window, completed recap, and inactive states. | Implemented in model/rules; Today and Track Fast consume it. |
| Tracker intention continuity | Starting and ending fasts preserve intention and review context. | Active and completed sessions store optional `intentionId`; sessions store optional `reviewNote`. | Implemented with serialization defaults for old sessions. |
| Recap after ending | Completed fasts produce pastoral recap and suggested next action. | Recap text is generated by rules and shown near top of Track Fast. | Implemented for completed, short, and medically prudent fasts. |
| Formation continuity | Companion connects season plan, recovery, streak, and premium boundary. | Formation state comes from premium season/recovery engines and local completion state. | Implemented in snapshot; further visual polish remains. |
| Recovery precedence | Missed-day recovery outranks ordinary next actions. | Primary action precedence starts with recovery before medical/today/fast states. | Implemented and unit-covered. |
| Medical prudence | Medical dispensation/prudence changes guidance tone and action. | Medical profile routes primary action to Guidance and labels recap prudently. | Implemented and unit-covered. |
| Onboarding payoff | First setup lands on Today with meaningful Companion state. | Onboarding includes reminder tier, quote reminder, and first fasting intention. | Implemented and covered by the connected fresh-install onboarding test. |
| Premium boundary | Free users still get companion clarity; premium adds formation depth. | Companion snapshot exposes premium formation affordance without adding support tips or Apple scope. | Implemented as navigation to Setup/Premium sections. |
| Android-native design | iOS behavior is matched without copying Apple UI. | Material-native card hierarchy, chips, buttons, local-first copy. | Implemented in current surfaces; visual-regression and Figma handoff remain open tooling work. |
